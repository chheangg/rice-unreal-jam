# Tasks

If you want someone (or some agent) to do something, put it here instead of
asking in chat/DM. This is the one place to check for outstanding asks.

## How to file one

Copy `TEMPLATE.md` to a new file named `YYYY-MM-DD-short-slug.md`, e.g.:

```
tasks/2026-08-20-fix-osc-jitter.md
```

Fill in the fields. Keep it short — a task file is a pointer, not a spec.

## Lifecycle

- **Open** — filed, nobody's picked it up yet
- **In progress** — someone's on it (set `Assigned to` and mark status)
- **Done** — move the file into `tasks/done/` in the same commit that closes
  it out, so `/tasks` only ever shows what's still outstanding
